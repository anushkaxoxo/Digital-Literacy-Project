Project overview
This project focuses on building essential digital literacy skills required in today’s digital world. It covers online safety, professional presence, coding practice, collaboration tools, and cybercrime awareness.
The aim of this project is to help students understand how to use digital platforms responsibly, improve technical knowledge, and stay safe from online threats.
